Backup and restore

A backup holds the whole database: the masters, the staged imports, every revision, every review and lock, every closed month and every version issued from it. Keep the downloaded file somewhere other than this computer as well. Restoring replaces the database in use with the one inside the file.

Take a backup

The copy is taken while the tool keeps working, and it holds every change that had been saved when it started.

Restore from a backup

Choose a backup file and check it first. Nothing is replaced until you confirm, and a copy of the database in use is kept beside it before anything changes.
