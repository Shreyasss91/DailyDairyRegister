# Local office records — record_A

This is the local working folder for one office's filled data.

- Copy selected source templates from `data/templates/` into this folder; edit only the copies.
- Keep the original source documents, notifications, approvals and extraction provenance available.
- Do not commit filled DTC rosters, employee leave, real events, visit commitments, office-specific corrections, databases or backups.
- This directory is excluded from Git except for this README. Its contents remain local to the working copy.

Read `data/templates/README.md` before preparing files. It is the detailed data dictionary and explains supported importer datasets, source caveats, scheduling rules and capture-only boundaries.
